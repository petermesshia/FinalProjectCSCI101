This program reads coordinate and character data from a CSV file. It then stores the data in different vectors for the x-coordinate, the y-coordinate and the character value. These parallel vectors are sorted by in a coordinate pair ordering system and then are added to a 2D array. This 2D array maps the character values on a 2D grid. After everything is processed, the 2D array is printed to show a visual representation of the characters in their correct (y,x) spots. This allows for the final output to reconstruct the message that the CSV file was hiding. This code uses VS code as a source code editor. The code is then compiled and ran in the terminal on MacOS.
